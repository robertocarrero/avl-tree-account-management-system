# AVL Tree

C++ implementation of a self-balancing AVL tree with support for insertion, deletion, search, tree traversals, and automatic rebalancing.

## Features

* AVL insertion and deletion
* LL, RR, LR, and RL rotations
* Search by ID or name
* Inorder, preorder, and postorder traversals
* Tree height / level count
* Removal by inorder position
* Input validation for IDs and names

## Technologies

C++14, CMake
